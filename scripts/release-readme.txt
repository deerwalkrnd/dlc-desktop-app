DLC Desktop App
===============

1. Copy your lesson videos into the DLC folder next to this file.
   Sub-folders are fine. Each file must be named like this:

     TEACHER - LESSON NO - CHAPTER TITLE - LESSON TITLE - SUBJECT - OLD|NEW - CLASS.mp4

   Example:

     Arjun Khatiwada - 1.2 - Factorization of Polynomials - Polynomials in Maths - Mathematics - OLD - 8.mp4

2. Double-click dlc-desktop-app.exe. Your browser opens http://localhost:3000.
   Keep the black console window open while you use the app.

3. Added or renamed videos? Open the Library page in the app and press
   "Rescan library". No restart is needed.

To check a folder before copying it to the computers, run:

     dlc-check.exe DLC

It lists every file whose name is wrong and why.

Full guide: https://deerwalkrnd.github.io/dlc-desktop-app/
Requires Windows 10 or later.
